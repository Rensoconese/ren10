Why RenDS

Three pillars, no exceptions.

Every decision in the system ladders up to one of these three. If a feature can't live inside them, it doesn't ship.

1

Vanilla first

Pure HTML, CSS, and JS. Use <dialog>, <details>, and the Popover API before reaching for JavaScript. Web Components are for encapsulation, not for rendering.

2

Accessible by default

WCAG 2.1 AA minimum, AAA where it doesn't fight users. Every component ships with keyboard support, focus management, ARIA, and respects prefers-reduced-motion. Not an afterthought.

3

Atomic architecture

Tokens → Primitives → Composites → Patterns. Build upward, never skip a layer. A Button uses tokens. A Dialog uses buttons. A Form uses dialogs and fields.

What's inside

Four layers. No exceptions.
