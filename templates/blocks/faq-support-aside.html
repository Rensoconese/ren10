Where should a new project start?
Load the foundation, choose a page skeleton from the layout contract, then compose only the components the flow needs.
How do we report a component issue?
Include the component name, markup, browser, theme, expected behavior, and a minimal reproduction.
Can we copy these blocks?
Yes. Each block is a standalone vanilla example intended to be adapted with Ren10 tokens and contracts intact.
What should be verified before release?
Run lint and agent checks, then inspect responsive layout, keyboard flow, contrast, themes, and reduced motion in a browser.
