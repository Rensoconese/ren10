Working with the system

Everything your team needs to begin

Implementation answers stay visible beside the context that explains why they matter.

How do we install the package?
Install ren10 from npm or load the published CSS directly, then import only the component scripts your interface uses.
Where do layout decisions live?
Use the public layout primitives first: stacks, clusters, grids, centers, frames, reels, and sidebar compositions.
How are accessibility requirements documented?
Every component contract includes required semantics, keyboard behavior, focus expectations, and test coverage.
Can we adopt Ren10 gradually?
Yes. Start with tokens and a single primitive, then add composites and patterns as the product needs them.
