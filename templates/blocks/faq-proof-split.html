Are all components documented?
Yes. Every primitive, composite, and pattern has a colocated contract covering markup, public tokens, states, accessibility, and tests.
How does the library avoid framework lock-in?
The public surface is vanilla HTML, CSS, and JavaScript, with optional Light DOM custom elements for progressive behavior.
What does the accessibility baseline include?
Semantic elements, keyboard behavior, visible focus, readable contrast, reduced motion, and automated browser checks are required.
Can the system scale across products?
Yes. Semantic tokens and layout primitives create consistency while documented component tokens preserve controlled product-level variation.
