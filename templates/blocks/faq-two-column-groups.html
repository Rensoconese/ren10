Two Column Groups FAQ

Two independent disclosure groups create a denser desktop view and return to one readable column on smaller screens.

Find an answer without hunting

Related questions stay close while each column manages its own open state.

What browsers are supported?
Current Chromium, Firefox, and WebKit releases are covered by the component test matrix.
Does JavaScript gate the visual design?
No. Components paint correctly first; JavaScript adds coordinated state and interaction only where required.
Can we use native forms?
Yes. Ren10 enhances real labels, inputs, buttons, fieldsets, and validation states.
How are releases verified?
Lint, agent checks, accessibility tests, render tests, package smoke, and browser coverage run before release.
Are themes part of the package?
Yes. The default system and named appearances share one semantic token contract.
Where can agents find the API?
The root design contract routes agents to colocated component and pattern contracts.
