Implementation answers

Resolve the common questions first

Short, direct answers keep teams moving without turning the section into a documentation wall.

Where are component APIs defined?
Each component keeps its selectors, attributes, public tokens, states, and accessibility requirements in a colocated contract.
Can a block use custom layout CSS?
Only when the layout primitives cannot express the required anatomy. The page skeleton should still begin with Ren10 Grid, Stack, or another documented primitive.
How should spacing be chosen?
Use semantic spacing tokens and parent gaps. Avoid stacking unrelated child margins or introducing one-off pixel values.
