Catalog

Components

Every UI piece in RenDS, organized by atomic layer. Start from foundations, climb to primitives, compose into composites, ship as patterns. Each card links to a dedicated documentation page when one exists, or to the showcase example when it doesn't.

How to read this catalog. RenDS components ladder upward through four atomic layers: Foundations (raw HTML elements styled by tokens — no classes needed), Primitives (single-purpose, CSS-only components like a button or a tag), Composites (multi-part components that may need a sprinkle of JS — dialog, tabs, select), and Patterns (full-screen UX patterns like a data table or empty state). Cards marked Documented link to a full doc page with API, anatomy, accessibility notes, and live demos. The rest link to a quick visual reference in the showcase.

Layer 1

Foundations

Before there's a component, there's a foundation. Raw HTML elements styled by tokens. Layout primitives that take any content and arrange it. The token system that makes everything else themeable. Read these first; the rest is composition on top.
