Pattern

Multi-Step Form

Wizard with numbered stepper, per-step validation, back / forward / save-progress controls. For onboarding, checkout, complex setup flows.

About

Overview

Use a multi-step form when a single page would feel overwhelming or when steps depend on previous answers. Show a clear stepper so the user always knows where they are. Save progress between steps so a back-navigation doesn't lose data.

Live

Demo

  1. Account
  2. 2Profile
  3. 3Plan

Step 2 of 3 — current step content goes here.

<ren-multi-step current="2">
  <ol class="ren-stepper" aria-label="Setup progress">
    <li aria-current="step">Account</li>
    <li>Profile</li>
    <li>Plan</li>
  </ol>
  <form data-step="1">…</form>
  <form data-step="2" hidden>…</form>
  <form data-step="3" hidden>…</form>
</ren-multi-step>

Reference

API

ClassEffect
.ren-stepperThe progress indicator. Numbered ol with completed / current / pending states.
.ren-stepper-stepOne step. Use aria-current="step" for the active one.
.ren-stepper-step[data-completed]Past step (checkmark fill).

Pattern

  • Validate the current step before Next advances.
  • Allow free Back navigation — don't lose prior data.
  • Save progress to localStorage or the server so the user can leave and resume.
  • Last step is "Review" — show all entered data before final submit.

Inclusive by default

Accessibility

  • The stepper is a real <ol> with aria-label; current step uses aria-current="step".
  • Each step is its own <form> with its own focus management — autofocus the first input on step change.
  • Announce progress changes via a polite live region: "Step 2 of 3."
