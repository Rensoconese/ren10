Command Palette Requires JS

Searchable command launcher (⌘K). Fuzzy matching, keyboard-first, grouped by category. The fastest way for power users to do anything in the app.

About

Overview

Command palettes turn your app into a keyboard-first surface. Bind ⌘+K globally and let users type to find any action — navigation, settings, recently-used items.

Live

Demo

Press Ctrl+K — the palette's default global shortcut — or use the button, then type to filter.

Reference

API

ClassEffect
.ren-commandOn the <dialog> inside <ren-command>. Opens centered via showModal(), with a dimmed backdrop.
.ren-command-inputThe search input. A real <input type="text"> with an accessible name.
.ren-command-listThe scrolling results container.
.ren-command-group / -group-headingOptional grouping. The component sets data-empty on a group whose items are all filtered out.
.ren-command-itemOne command, as a <button>. data-value identifies it; data-keywords adds extra matching terms; data-action names a handler registered with registerAction().
.ren-command-emptyShown when the filter matches nothing. Start it hidden.

Attributes, methods and events

NameTypeDefaultNotes
data-shortcut"ctrl+k" | "meta+k" | …"ctrl+k"Global key combo that opens the palette. Bind only one.
open() / close()method—Open or close the palette from your own trigger.
registerAction(id, fn)method—Runs fn when an item with a matching data-action is selected.
ren-command-selectevent—An item was chosen. { item, value, action }.

Inclusive by default

Accessibility

  • Rendered as a real <dialog> opened with showModal(), so the focus trap, Esc, and the inert background all come from the browser.
  • Up / Down navigate, Enter runs the command, Esc closes. The component injects a role="status" live region that announces the result count on every keystroke.
  • Always include keyboard fallbacks for users who can't reach the ⌘K shortcut — every command should also be reachable from a visible trigger or a menu.
