Pattern

Data Table

Sortable, filterable, paginated table with sticky header, row selection, and density toggle. The workhorse of every CRUD admin.

About

Overview

Use Data Table for any tabular dataset users will sort, filter or scan: invoices, users, orders, logs. Pair with Pagination below for paginated views or with infinite scroll for activity feeds.

Reference

API

ClassEffect
.ren-data-tableApply on the <table>. Adds borders, padding, sticky header, row hover.
.ren-data-table-toolbarOptional row of filters / search / column toggles above the table.
.ren-data-table-empty"No results" state inside the tbody.
.ren-data-table-density-compactTighter row height for dense data.

Inclusive by default

Accessibility

  • Use semantic <table> + <thead> + <tbody>. Don't fake tables with divs.
  • Sortable columns: header is a <button> with aria-sort="ascending" / "descending" / "none".
  • Row selection: each row has a <input type="checkbox"> in the first cell with a real <label> linking it to the row identifier.
