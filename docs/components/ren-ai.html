Pattern

AI Patterns

Conversation thread, message bubble, streaming-text indicator, suggestion chip. The starter kit for building chat-based AI features.

About

Overview

AI chat surfaces share a small vocabulary: a thread of alternating bubbles, a streaming response indicator, action buttons under the latest assistant message, and suggested prompts when the user might be stuck. RenDS provides the visual primitives; you bring the inference layer.

Live

Demo

What's the difference between a Tooltip and a Popover?
Tooltip is a passive hint shown on hover or focus — typically just text. Popover is interactive: it can hold forms, multiple actions, anything keyboard-navigable. Tooltip never traps focus; Popover does.
<div class="ren-ai-thread" role="log" aria-live="polite">
  <div class="ren-ai-msg ren-ai-msg-user">…</div>
  <div class="ren-ai-msg ren-ai-msg-assistant">
    Streaming response…
    <span class="ren-ai-cursor"></span>
  </div>
</div>

<div class="ren-ai-suggestions">
  <button class="ren-tag ren-tag-clickable">…</button>
</div>

Reference

API

ClassEffect
.ren-ai-threadScroll container for messages. role="log", aria-live="polite".
.ren-ai-msgOne message. Combine with -user or -assistant for direction-aware bubble shape.
.ren-ai-cursorBlinking cursor that appears at the end of streaming responses.
.ren-ai-suggestionsRow of suggestion chips below the latest assistant message.
.ren-ai-actionsTrailing slot under a message: copy, regenerate, thumbs up/down.

Inclusive by default

Accessibility

  • The thread is a live region — screen readers announce new messages as they arrive.
  • Don't auto-scroll while the user is reading — pause auto-scroll when the user manually scrolls up, resume when they reach the bottom.
  • Streaming responses: announce the final text once when complete, not character by character.
  • Always provide a "Copy" action on assistant responses — it's the most-used affordance.
